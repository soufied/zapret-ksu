    Private DNS
    -

    Routes DNS (port 53, IPv4 and IPv6) of every app through encrypted DoH servers, using dnscrypt-proxy on 127.0.0.1:5354. Private DNS is turned off while the proxy runs. Browsers with their own Secure DNS on use it instead and skip the proxy. With Secure DNS off, they use the proxy like every other app.

    Providers

    Ticked providers are used together, and the fastest one answers first. "Blocking only" ticks the malware and ad blockers, without the ones that send your client subnet.

      Android Private DNS

      Alternative to the proxy. It encrypts DNS with DNS over TLS for every app. It cannot run together with the proxy.

      Changes take effect when the firewall restarts. Applying restarts it automatically when it is running.

      Blockcheck

      Finds the preset that gets your blocked domains through. Each domain is checked over HTTP, TLS 1.2, TLS 1.3 and QUIC. First a baseline with no bypass, then the same baseline with encrypted DNS (DoH, or DoT if DoH is unavailable). If encrypted DNS makes more domains available, every preset is tested with it on. Traffic is briefly interrupted while it runs. The app filter is switched off for the run, so the test traffic goes through the engine, and restored afterwards. Needs curl.
